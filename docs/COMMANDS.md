# 搜索、命令与快捷键

按 `Ctrl K` 打开“搜索与命令”，普通关键词会优先显示匹配的聊天，也能查找聊天正文和已归档内容。按 `Ctrl Shift P`、点击窗口顶部的命令入口，或在搜索词前输入 `>`，只显示命令。聊天标题不会匹配置顶、归档等修改动作；选择聊天只打开该聊天并恢复它自己的草稿。

命令包含新聊天、页面导航、设置、显示或隐藏侧边栏、主题切换、当前聊天的重命名／置顶／归档／Markdown 导出，以及已启用和授权的插件命令与面板。当前聊天正在生成回复时，重命名、置顶和归档不可执行。导航沿用现有草稿保存流程，不会发送消息或移动其他聊天的附件。导出取消保留搜索窗口，保存失败保留关键词和错误提示，排除故障后可重试。

在项目页选择项目后，“当前项目”提供文件树、终端和审阅面板的显示／隐藏命令，与工具栏共用当前状态。审阅期间文件树命令停用，返回文件面板后恢复；隐藏终端保留正在运行的进程和输出，恢复后继续使用同一个终端。面板选择在同一窗口内跨页面保留，重启后默认显示文件树、关闭终端并进入文件面板。其他页面、尚未选择项目或项目已删除时，这三项停用并说明原因。项目名称只作为描述，不会匹配面板修改命令。执行前重新加载工作台并核对当前项目、面板状态和命令方向，过期命令保留搜索词和错误，刷新后可重新选择。

使用 `↑`／`↓` 循环选择可用结果，`Home`／`End` 选择首尾可用结果，`Enter` 执行，`Esc` 关闭并返回原输入位置。搜索框使用 combobox、listbox 和 active-descendant 语义，禁用结果不能通过 Enter 执行。窗口打开时暂停工作台导航快捷键；输入法正在组词时，Enter 不执行命令。搜索最多 512 个字符，单次最多显示 30 个聊天、100 个总结果；关键词按字面量、忽略大小写匹配，不执行正则表达式或代码。

搜索“键盘快捷键”可查看现有绑定：`Ctrl N` 新聊天、`Ctrl ,` 设置、`Ctrl B` 侧边栏、`Alt 1–9` 最近聊天，以及上述搜索和选择快捷键。`Ctrl F` 或“查找当前聊天”命令打开正文查找条，`Enter`／`Shift Enter` 定位后续／前一个结果，`Esc` 关闭；只有实际显示聊天时可用，生成回复期间也可查找。行为及范围见 [聊天导航文档](CHAT-NAVIGATION.md)。系统托盘与全局唤起快捷键仍在外观设置中单独启用，见 [桌面入口文档](DESKTOP-INTEGRATION.md)。

选择插件命令先打开参数预览，不会立即运行。检查纯文本说明、填写有效 JSON（最多 64000 个字符），选择“命令所用项目”，再点击“执行命令”。参数保留 Unicode、换行及字面量，不解释 HTML 或表达式；对象、数组和 JSON 基本值都可传递。默认不选择项目，列表只包含插件已有作用范围内的项目；项目访问及写入继续走原有权限和审批路径。结果以纯文本显示，参数格式或命令执行失败后保留输入。

只有已启用且授权对应能力的插件贡献会显示，运行尚未就绪的项目显示为不可用。“刷新命令”重新读取插件状态和权限；撤销命令权限后，已有参数仍保留，执行按钮停用。面板使用独立的授权和来源隔离，不能绕过命令权限。完整备份恢复的插件默认停用且无授权，因此不会因为搜索或恢复自动执行。格式与权限说明见 [插件文档](PLUGINS.md)。

命令目录和搜索交互参考外部 OpenCode 的统一命令／会话／文件选择及 Chatbox 的命令对话框，采用独立实现，没有导入竞品代码或界面资产。目录与参数函数的行、分支及函数覆盖率均为 100%。18 项命令单元检查覆盖目录、同名项、字面量搜索、聊天优先级、权限／运行状态、生成中限制、键盘选择、精确参数限额及项目切换方向／失效状态。现有命令的 6 项聚焦原生检查、包含两项项目命令检查的 7 项项目专项检查，5 项聊天导航／查找检查，以及同一份实际 EXE 的 173 项完整回归均通过，并正常退出。结果绑定实际 EXE／ASAR 校验值，见 [项目验证记录](../verification/project-tree-review-result.json)。两次完整回归的重载快捷键等待和 PowerShell 内存异常现场已保留；补上工作台加载等待后完成命令复核和最终完整回归，未放宽超时或移除检查。原生检查使用真实工作台、隔离插件运行时、HTTP、磁盘错误、正常退出／重启和完整 gzip 恢复；输入法事件、文件选择／确认与权限准备使用隔离测试边界。物理输入法、原生系统选取、辅助技术、最大规模性能及其他平台仍需单独验证。
