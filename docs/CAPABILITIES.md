# Nook 能力与边界

Nook 是本地 AI 工作台，面向聊天、文档和项目。下表区分已有实现与剩余交付范围；已有实现不代表所有平台、真实云服务或最终安装包均已验收。

当前证据见[发布状态](RELEASE.md)，界面采用范围见[设计对照](DESIGN-ALIGNMENT.md)，完整交付要求见[交付记录](DELIVERY.md)。尚未发布版本。

## 如何看验证记录

本地协议服务和隔离测试数据证明程序行为，不证明真实云端模型的质量。测试中替代的文件选择／确认窗口不等于物理操作系统交互验收。覆盖率针对实际纳入统计的模块，不代表全部界面覆盖率。

源码、未安装应用、实际安装版和便携版分别验收；每批证据只适用于记录的提交与文件哈希。历史通过不能替代后来修改的完整验收。

原有能力表、逐批测试数字、失败原因与未完成项完整保留于[能力审计历史](CAPABILITIES-HISTORY-2026-10-05.md)。正文整理没有取消其中的剩余交付范围；详细行为和验收边界仍以对应功能文档及实际证据为准。
