# Nook 能力

本地 AI 工作台。连接模型，处理资料，推进项目。

| 工作 | 可以做什么 |
| --- | --- |
| 对话 | 流式回复、停止与重试、消息编辑、回复版本、对话分支、2–4 模型比较、上下文摘要 |
| 资料 | 导入文档与图片，检索资料集，离线阅读 PDF 原件、目录和查找，导出原始文件 |
| 项目 | 文件树、代码编辑与草稿、真实终端、HTML 预览、Git 审阅、暂存与提交 |
| 工作树 | 创建、登记、会话关联、固定、私有快照、新目录恢复及可选自动清理 |
| 助手 | 工作指令、变量提示模板、显式记忆、MCP 工具与资源、本地技能、隔离插件 |
| 自动任务 | 一次、周期与 Cron 安排，查看执行结果，暂停、继续或手动运行 |
| 日常操作 | 搜索与命令、输入区快捷选择、快速聊天、临时浏览器、本地备份与恢复 |

支持 Responses、OpenAI 兼容接口、Anthropic、Gemini、Azure 和 Ollama。连接与凭据由你配置；模型请求发往所选服务。

明暗主题共享对话和代码字号偏好。长表格支持键盘滚动、展开及 Markdown／HTML 复制；窄窗口保留滚动边界。未保存设置和失败操作保留草稿供重试。

聊天与项目配置保存在本机，凭据由系统加密，完整备份不含密钥。临时聊天不进入持久历史或完整备份；恢复后的插件需要重新授权。文件修改、命令和远程工具沿用具体操作审批。

会话中的任务步骤用于记录进度，完成标记不代替实际工具结果。远程 SSH、语音、OCR、模型下载管理及远程同步尚未提供。

当前为尚未发布的 Windows x64 预发布候选。全部参考页面、物理系统交互和实际服务质量仍需对应验收；当前结果见[发布状态](RELEASE.md)、[设计对照](DESIGN-ALIGNMENT.md)与[界面验收](UI-ACCEPTANCE.md)。

此前的验证轮次与失败范围完整保留于[历史记录](CAPABILITIES-HISTORY-2026-10-16.md)，只证明各自对应的源码和产物。
