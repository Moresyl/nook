# 助手配置导入与导出

“助手”页面可导出全部配置，也可在单个助手旁选择“导出”。共享文件使用独立的 `qiyao-assistants` 格式，版本为 `1`，只包含名称、简介和工作指令。文件不包含工作台 ID、模型连接、密钥、对话、项目、技能或插件配置。工作指令是用户填写的文本；分享前可在编辑窗口查看。

导入支持 JSON 和按内容识别的 gzip JSON，UTF-8 可带 BOM。文件及解压后文本均不得超过 4 MB，每个文件最多 1000 个助手；单个工作指令最多 32000 个字符。未知字段、非支持版本、损坏压缩包、无效 UTF-8、空名称和超限数据均拒绝导入。需要分享较大的工作台时，可逐个导出助手。

选定文件后会打开预览，可切换查看每个助手的简介和完整指令。预览将文本原样显示；确认添加前不会写入工作台，也不会请求模型或执行指令。取消会关闭预览。确认后在一次工作台事务中添加全部助手，每个助手获得新的 ID，同名的既有助手保持不变。写入失败保留预览和已有配置，可关闭提示后再次添加。

导出复用完整备份的有界流与原子文件替换：先校验完整内容，写入同目录临时文件并同步，最后替换目标，失败清理临时文件。助手文件操作采用独立的并发限制，同时只能执行一项助手文件读写；应用退出时会取消未完成的文件操作。

导入后的助手可手动选择“开始聊天”，工作指令通过现有会话引擎与项目指令组合。删除助手会清除对话、消息草稿和自动计划中的对应选择，保留消息、草稿文字和计划。延迟草稿写入也不能恢复已删除的助手引用。完整工作台备份保留这些助手配置。

实现参考了外部 Cherry Studio 的可移植助手记录、AionUI 的助手管理与 Chatbox 的独立指令组合；没有导入其代码、头像或内置指令。原有法律文件保持不变。单元检查覆盖严格格式、精确 UTF-8 限额、真实文件与重启、并发容量、失败回滚和引用清理；桌面验证覆盖导入预览、取消、导出、磁盘失败、真实模型请求和完整备份。原生选取／确认弹窗及模拟 EIO 使用隔离测试边界，实际系统选取弹窗和其他平台仍待审计。
