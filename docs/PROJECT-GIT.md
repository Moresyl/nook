# 项目分支

在项目页选择“查看改动”，点击当前分支，打开本地分支列表。输入名称查找，点击分支即可切换；“新建分支”从当前版本创建并切换，支持中文名称和 Enter 提交。每行右侧提供重命名和删除入口。

重命名可修改当前分支或未占用分支的名称。输入新名称后按 Enter 或选择“保存名称”；重复和无效名称会被拒绝，原输入保留。提交、暂存区、文件改动、跟踪配置与编辑草稿保留，其他工作树正在使用的分支不能在此改名。

删除会先展示具体分支，再由“删除分支”执行；取消不会修改引用。当前分支、工作树占用分支，以及未完全合入当前版本的提交均会保留。Git 的常规上游合并保护仍生效，跟踪上游尚未合入时也可能拒绝删除。文件、草稿和远程分支保留，不提供强制删除。

列表标明当前分支与“其他工作树”。其他工作树正在使用的分支不能在此切换。名称无效、重复、存在合并冲突或切换会覆盖工作区改动时，操作会被拒绝；输入保留，可解决问题后重试。操作期间关闭、取消、输入和重复提交暂停，避免误操作。

切换前保存工作台中的编辑草稿。切换后刷新文件树与干净文件；未保存草稿及其原始比较基线保留。新分支中无法读取的已打开文件保留上次内容并显示提示。保存时仍检查磁盘版本，遇到冲突先比较内容。切换会关闭该项目的浮动和并排 HTML 预览。

Git 钩子可能在 HEAD 已切换后报错。这时界面显示实际分支和后续步骤错误提示，不泄露钩子的原始输出。同一共享仓库的 Git 修改操作排队执行，使用常规切换保护，不自动丢弃文件或强制覆盖。

目前支持本地分支创建、切换、重命名和安全删除；独立工作树见[工作树说明](PROJECT-WORKTREES.md)。远程拉取／推送与凭据窗口仍待实现。快捷聊天窗口不开放项目 Git 接口；外部 Git 进程不经过应用内操作队列。

新分支字段采用最新资料中的自动焦点、标签、受控输入、重复错误、禁用状态，以及 4px 间距、12px 横向内边距和 8px 顶部内边距。整体弹窗、分支列表、输入边框与焦点样式沿用 Nook 的共享控件，不代表全部参考界面已还原。
