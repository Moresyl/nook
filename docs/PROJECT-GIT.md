# 项目分支

在项目页选择“查看改动”，点击当前分支，打开本地分支列表。输入名称查找，点击分支即可切换；“新建分支”从当前版本创建并切换，支持中文名称和 Enter 提交。

列表标明当前分支与“其他工作树”。其他工作树正在使用的分支不能在此切换。名称无效、重复、存在合并冲突或切换会覆盖工作区改动时，操作会被拒绝；输入保留，可解决问题后重试。操作期间关闭、取消、输入和重复提交暂停，避免误操作。

[分支查找原图](images/project-branches-search.png) · [名称错误原图](images/project-branches-invalid.png) · [深色窄窗 150% 原图](images/project-branches-dark-150.png)

切换前保存工作台中的编辑草稿。切换后刷新文件树与干净文件；未保存草稿及其原始比较基线保留。新分支中无法读取的已打开文件保留上次内容并显示提示。保存时仍检查磁盘版本，遇到冲突先比较内容。切换会关闭该项目的浮动和并排 HTML 预览。

Git 钩子可能在 HEAD 已切换后报错。这时界面显示实际分支和后续步骤错误提示，不泄露钩子的原始输出。Git 修改操作按项目排队，使用常规切换保护，不自动丢弃文件或强制覆盖。

目前支持本地分支创建与切换；远程拉取／推送、分支删除／重命名和工作树创建界面仍待实现。快捷聊天窗口不开放项目 Git 接口。

新分支字段采用最新资料中的自动焦点、标签、受控输入、重复错误、禁用状态，以及 4px 间距、12px 横向内边距和 8px 顶部内边距。整体弹窗、分支列表、输入边框与焦点样式沿用 Nook 的共享控件，不代表全部参考界面已还原。

专项验证使用真实本地仓库、工作树、钩子、桥接和 Monaco，共八组通过；覆盖 219 个分支、覆盖冲突与重试、草稿基线、预览清理、真实重启及两主题三档缩放。十三张原始窗口截图已逐张检查；文字溢出断言在旧构建上失败、修复后通过。[验证记录](../verification/project-branches-review-result.json) 仍需最终安装包、物理输入与辅助技术验收。
