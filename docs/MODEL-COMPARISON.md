# 并行模型比较

本轮验收见 [源码记录](../verification/model-comparison-review-result.json) 与 [本机分发记录](../verification/model-comparison-distribution-result.json)。远端及完整项目交付另见 [发布流程](RELEASE.md)。

最新状态通知修复通过 594 项／58 个文件单元测试、类型检查、构建、六项专项桌面检查和完整 194 项源码桌面回归并正常退出；九张当前完整回归截图已逐张检查。新增检查实际延迟第二条流的旧启动快照，确认它不能覆盖第一条流已经保存的部分文本；修复前失败，修复后通过。状态事件发送时现在读取最新已保存状态。新本体的分发与远端验收正在进行；初版远端通过 189 项后失败，原因尚未成立，详见 [远端比较失败记录](CI-MODEL-COMPARISON.md)。

继续某条对话时可以更换连接和模型。比较卡片仍显示生成原始回复时记录的连接名称与模型，不借用后续请求的身份；没有原始请求记录时会明确显示“未记录”。这项后续标注修复已通过 593 项／58 个文件单元测试、类型检查、构建和六项实际桌面比较检查，包含更换连接及模型后的原回复预览和备份恢复。完整源码复验通过 194 项并正常退出，九张当前完整回归比较截图已逐张检查；新应用本体的分发／远端验收仍在进行；下文 590 项和本机分发记录属于初版比较的独立提交。

在输入框填写问题、选择当前助手与项目并准备附件后，点“比较”。选择 2–4 个不同的提供商／模型，点“发送并比较”才会发起请求。浏览选择、预览和取消不会请求模型；重复的提供商／模型组合不能发送。模型必须已经配置，所有连接、密钥、当前上下文和附件会先检查，通过后才一起保存新的对话路径。

每个模型收到相同问题、当前完整消息上下文和附件，使用当前助手与项目说明，以聊天方式运行；本次比较不调用工具或检索新资料。当前聊天及未发送草稿保留。两到四条回复同时生成，各自拥有完整后续上下文，可以单独停止或打开继续；一个模型失败不会取消其他请求。预览显示本次问题的回复，继续聊天后仍能打开“查看比较”，各条草稿保持独立。

比较中的文本预览只读，HTML 和标记按原文显示。普通比较记录随本机历史、JSON／gzip 完整备份和重启保留；临时聊天发起的整组比较继承临时保存方式，不进入历史与完整备份，关闭应用后清除。明确导出的聊天及模型服务收到的请求遵循各自保存方式。

创建整组时保存失败会保留原始聊天、草稿、选择和历史字节，可以直接重试；提交前发现上下文变化、正在生成、连接被移除或历史限额已满时，不发起模型请求。已启动的各条对话使用现有执行、停止、保存和恢复机制。窗口关闭时等待尚未完成的组创建操作，避免退出后继续创建记录。

原文档案、编辑分支和手动分支保留各自消息，不继承原组成员标记；每组最多四条独立路径。分支排序、模型选择、回复重试和消息编辑仍使用各自原有操作。最小窗口沿用共享弹窗、固定底部按钮和原有控件；较高缩放下选择与结果区域可滚动。

当前源码通过 590 项单元测试／58 个文件、类型检查和构建。比较契约达到全部覆盖率 100%；发布策略与十份记录读取的 30 项测试也达到行、语句、函数和分支 100% 覆盖率。六项独立桌面检查使用真实本地 HTTP、同时保持两条流、四模型故障／停止、真实保存失败重试、后续对话以及完整备份恢复和重启。完整源码桌面回归通过 194 项并正常退出，六项比较检查共发出十一条真实本地 HTTP 请求；当前完整回归的九张截图已经逐张检查。应用包与实际安装版各通过完整 194 项回归并正常退出，四项设置、七项便携检查、中文路径安装、快捷方式和卸载保留数据均通过；十份实际记录匹配本轮同一应用。九张当前安装版比较截图已逐张检查，远端验收仍在进行。
