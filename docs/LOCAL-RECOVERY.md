# 本地恢复副本

工作台每次提交前，将完整上一版持久化 JSON 保存为 `workspace.backup.json.gz`。压缩只改变文件编码，解压后的内容和字节顺序与上一版完全相同。文件仍经过同步落盘和原子替换；副本写入失败时，不发布新工作台状态。

此副本用于本机恢复，仍依赖本机的技能、插件和原始文档目录。跨设备迁移请使用设置中的完整工作台备份，它会同时携带这些资源。密钥不在 JSON 中，临时聊天及其独有附件不进入持久化副本。

较早版本生成的 `workspace.backup.json` 保留，便于必要时手动检查；升级后的最新自动副本是 `.json.gz` 文件。主文件 `workspace.json` 和响应检查点的格式不变。现有备份读取入口按文件头识别 gzip，也继续接受旧版纯 JSON。

压缩用于减少大型工作台反复同步完整副本的写入量，不取消同步、不推迟保存确认，也不增加交互或测试的等待时限。性能取决于数据压缩率和磁盘；不能据此保证任意大小工作台的固定保存耗时。
