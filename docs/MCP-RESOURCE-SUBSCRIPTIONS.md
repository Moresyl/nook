# MCP 资源更新订阅

在设置的“MCP 工具”中连接服务器，打开“资源与提示词”，选择资源或填写目录中允许的资源模板，点击“订阅所选资源”。服务器声明支持订阅时才启用这个入口；不支持订阅的服务器仍可以手动读取资源。

订阅后，当前所选资源收到更新通知时会自动刷新只读预览。连续通知合并处理，同一所选资源按顺序读取；每次读取完成就显示内容，再处理等待的更新，避免持续通知导致预览一直为空。切换资源后旧请求不能替换新资源的预览；HTML 等标记仍作为原文显示。预览不会自动发送模型请求，也不会改写已有消息或草稿，持续刷新时仍可手动点击“用于对话”，随后在消息框中修改。

每个连接最多订阅 20 个资源。可以停止所选资源，也可以从订阅清单逐条停止。重复订阅不会重复请求服务器，同一连接上的订阅与取消按顺序执行；失败保留可重试的状态，错误不会显示远端敏感详情。被目录移除的资源停止在本机接受更新，并尝试通知服务器取消。

订阅属于当前连接，断开、删除连接、退出或重启后停止；配置和原有聊天草稿继续遵循各自的保存方式。资源更新通知不会加入聊天历史或完整备份。
