# 临时聊天

侧边栏中的“临时聊天”会创建独立对话。输入文本、附件、模型及助手选择按这段对话单独保留；切回普通聊天或新聊天时，会恢复各自的未发送草稿。最近聊天里的临时对话带有“临时”标记，输入栏持续显示保存范围。

临时聊天的消息、附件、输入草稿、消息编辑草稿、分支和旧回复版本只在本次应用运行期间保留，不写入 `workspace.json`、`workspace.backup.json.gz` 或完整 JSON／gzip 工作台备份。退出应用后不会恢复这些内容，普通聊天与草稿照常保存。关闭到托盘时应用仍在运行，临时聊天也仍在内存中；从托盘退出或真正关闭应用才会清除。重新加载界面不会退出应用。

所选模型服务仍会收到消息；临时聊天不改变模型服务自己的记录方式。主动导出聊天会保存选中的内容，工具或插件执行的文件、命令和网络操作仍产生各自结果。单独修改的设置、项目和资料库也照常保存。已有对话的保存方式固定，不能把临时聊天切换成普通聊天或反向转换。

临时对话在内存中沿用普通对话的发送、停止、重试、编辑及分支功能。保存时统一筛除所有临时拥有者，保留最后的普通对话选择；仅改变临时内容时不写历史文件。普通数据写入失败会报错并保留当前内存内容。含临时对话标记的历史文件或导入备份会被拒绝，原始文件不会被覆盖。

当前增量的完整单元回归为 545 项、55 个文件；临时聊天有 12 项针对性测试，发布策略另有 25 项测试且达到 100% 覆盖率。六项实际桌面检查覆盖附件读取和独立草稿切换、三次本地 HTTP 模型请求的发送／重试／停止、原生分支和编辑草稿、完整 JSON／gzip 备份排除、主动 Markdown 导出，以及实际退出重启后的清除和普通草稿恢复。100%／125%／150% 缩放会等待实际视口尺寸稳定后检查几何位置，并捕获完整 Electron 窗口。

完整源码、实际应用包和已安装版本均通过 185 项桌面检查与正常退出，其中包含六项临时聊天检查及六项分支恢复检查。本次分发还通过四项设置、七项便携版检查、两次长路径启动退出，以及安装／快捷方式／卸载保留数据验证；九份实际记录独立通过同版本发布策略。12 张源码分支／临时聊天截图及四张当前安装本体的临时聊天截图已逐张检查。远端流水线 [37114355094](https://github.com/Moresyl/qiyao/actions/runs/37114355094) 在聊天导航尺寸等待中失败，未完成本次远端验收。本机已复现 125% 前置状态并修复测试，见 [缩放检查](CI-CHAT-ZOOM.md)。发布检查要求各记录匹配同一 EXE／ASAR 校验值；旧本体的记录不能通过新检查。文件对话框使用隔离的测试响应，这不代表物理系统选择器或图形安装向导已验收。见 [源码运行记录](../verification/temporary-conversations-result.json)、[同版本分发记录](../verification/temporary-distribution-result.json) 和 [发布流程](RELEASE.md)。
