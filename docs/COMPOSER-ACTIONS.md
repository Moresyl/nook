# 输入区快捷选择

在消息输入区的开头，或空白后输入 `/`，继续输入名称即可查找提示模板、助手和项目。主工作台与快速聊天都可使用。

- 用方向键选择，`Home`／`End` 跳到首尾，`Enter` 应用。
- `Esc` 关闭菜单并保留原文；`Tab` 关闭菜单并继续正常移动焦点。
- 选择模板后填写变量，按「插入到草稿」替换光标处的查询片段。取消保留原文；原有模板按钮仍追加到草稿末尾。
- 选择助手或项目保留查询前后的内容。已有工具、技能和资料集还提供相应选择入口。

选择操作不会发送消息。没有匹配项时，回车保留当前内容；关闭菜单后再按正常方式发送。`Ctrl+Home`／`Ctrl+End` 和带 `Shift` 的选区操作仍移动文本光标。输入法正在组词时不使用菜单快捷键。

菜单列出最多 100 个结果，可以继续输入缩小范围；长名称会省略显示，结果列表可单独滚动。URL、路径中间和已有文本选区不会触发菜单。模板表单打开后若草稿已变化，会拒绝使用旧查询替换新内容。

这项功能保留现有纯文本草稿格式。实际系统输入法、系统 DPI、完整参考交互和新发行包按各自验收范围记录。
