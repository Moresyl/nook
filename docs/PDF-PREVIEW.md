# PDF 原件与预览

新导入的 PDF 同时保留提取文本和经过内容校验的原件。附件预览可以切换原始页面与提取文本，翻页、调整缩放、适合宽度、选择文字，以及保存完整 PDF。目录支持嵌套章节、命名目标及页内位置；没有页内目标的外部动作不在目录中激活。旧附件没有原件时继续显示其提取文本。

全文搜索按页面文字进行不区分大小写的字面查找，保留文字片段和 Unicode 偏移，支持跨页高亮及上一处/下一处循环。Ctrl/Cmd+F 聚焦搜索框，框内 Enter 前进，Shift+Enter 后退。修改查询或销毁查看器会取消旧搜索。点击目录或手动翻页时，高亮保留，但停止自动返回旧匹配位置；再次选择上一处/下一处会恢复匹配定位。搜索最多显示 10,000 处匹配并明确提示截断；查询上限 512 字符，单页搜索文字上限 100 万字符、整份文档合计 1600 万字符，超限显示错误。

原件按内容去重，工作台记录仅保存哈希、字节长度和媒体类型。临时对话中的独有原件驻留内存；正式保存成功后，原件随消息、草稿、资料与保留引用共同维护归属。读取和导出均检查当前归属。保存失败保留暂存内容以便重试。

页面链接支持文档内部目标和系统浏览器打开的 HTTP/HTTPS 地址；带账号密码的地址、脚本和其他动作不激活。注释按钮打开只读内容，标记按纯文本显示；单条最多显示 32,000 个字符并提示截断。点击区域随页面视口转换和缩放，单页超过 10,000 项注释时显示错误，不影响原始页面阅读。这不是注释编辑器，也不提供表单填写。

完整备份携带所有持久化原件，恢复前验证原件集合、编码、长度及哈希。临时对话的独有原件不进入备份。原件内容不会作为 PDF 附件的模型输入，模型继续接收提取文本；端到端 HTTP 验证仍需补充。

## 离线资源与限制

查看器按需加载，在本地 Worker 中解析 PDF。字体、CMap 和图像解码资源随界面包嵌入，保留其现有第三方许可。CSP 允许 WebAssembly 编译以支持图像解码，不启用 JavaScript `unsafe-eval`。页面画布限制为约 1600 万像素，缩放范围为适合宽度的 25% 至 300%。

现有导入器仍要求 PDF 可提取文本，尚未提供扫描件 OCR 或密码输入流程。更多中文及复杂图像样本、所有缩放比例的可访问性验收尚未完成。目录超过 10,000 项、包含循环或结构无效时显示错误，页面浏览仍可使用。无引用原件的磁盘清理必须保护恢复用备份和检查点，目前保留这些文件。

## 验证边界

资源单元测试比对嵌入的 CMap、字体和解码器原始字节。桌面专项使用真实两页 PDF、真实解析 Worker、画布和文字层，检查翻页边界、缩放、视图切换、文字选择、原件导出、拒绝无归属引用与重启恢复。

专项运行：`$env:QIYAO_TEST_PDF_PREVIEW_ONLY='1'; node scripts/verify-desktop.mjs`。保存文件对话框在隔离测试进程内拦截，不代表实体文件选择器的人工验收。该专项尚未纳入完整桌面回归和发布证明门槛，不能据此宣称完整功能或发布验收通过。
