# 托盘与全局唤起

设置中的“外观与交互 → 桌面入口”可启用系统托盘、关闭窗口后保持运行及全局唤起快捷键。三项默认关闭，旧工作台和旧备份继续使用原来的退出方式。托盘使用 Nook 图标，菜单提供“打开 Nook”、“快速聊天”和“退出 Nook”。

开启“关闭窗口后保持运行”需要已启用托盘。关闭时仍先等待消息及编辑器草稿保存；保存失败会保留窗口。保存成功后隐藏同一个窗口，已开启的自动计划继续执行。点击托盘或按已注册的快捷键可恢复工作台，包括原对话、未发送消息和仍在编辑的设置。该入口不会自动发送消息或创建新的对话。

全局快捷键默认使用 `CommandOrControl+Alt+Space`，也可填写 `Ctrl+Alt+Space`、`Ctrl+Shift+F12` 或 `Ctrl+Alt+Shift+F12`。「快捷键打开」可选择工作台或[快速聊天](QUICK-CHAT.md)，旧设置默认继续打开工作台。格式要求 Control／Command 类修饰键、Alt／Shift 以及一个字母、数字、Space 或 F1–F12；修饰键不能重复。设置会检查实际注册结果，被其他软件占用时保留原有快捷键和设置。

托盘和快捷键变更先准备新资源，再保存工作台，成功后释放被替换的资源。保存失败会撤回本次取得的资源，保留原有入口。软件只注销自己取得的快捷键；停用和退出后的旧回调不能重新打开窗口。启动时若入口无法启用，窗口仍可正常退出，可在设置中停用冲突选项或更换组合后重试。

“退出 Nook”和应用菜单的退出始终退出整个进程，即使已开启后台运行。退出先完成草稿保存，停止自动任务和模型工作，关闭扩展及终端，再写完本地数据。恢复完整工作台备份会保留快捷键组合，但停用托盘、后台关闭和全局快捷键，并释放已有入口；确认设置后再主动启用。

单元检查覆盖旧数据兼容、格式限制、实际落盘、资源复用、候选回调隔离、注册失败、磁盘失败、串行变更、关闭竞态、清理失败、重启与备份停用。桌面验证使用真实 Electron 托盘、快捷键注册、窗口显示状态及后台计时模型请求；托盘／键盘回调送达、快捷键冲突和文件写入失败使用隔离测试边界。实际系统托盘的鼠标操作、操作系统键盘事件送达、启动冲突和其他平台仍需单独验证。独立浮动快速聊天已接入源码，新的完整桌面与分发验收见[发布状态](RELEASE.md)。
