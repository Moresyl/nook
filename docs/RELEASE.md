# Nook 发布状态

**尚未发布。** Windows x64 目标版本为 `0.1.0-alpha.1`。项目名称为 Nook；当前中文提示构建来自 `d2196b0`，类型、构建、977 项单元测试，以及源码、未安装版、实际安装版三轮完整 252 组桌面回归通过，各 37 次正常退出。包体／启动组件审计、真实便携包装和安装／卸载通过，最终 11 份匹配运行记录已通过发布策略检查；全部设计页面和托管流水线尚未完成验收。

仓库：[Moresyl/nook](https://github.com/Moresyl/nook)。完整要求见[交付要求](DELIVERY.md)，功能与界面进度见[能力与边界](CAPABILITIES.md)和[设计对照](DESIGN-ALIGNMENT.md)。设计资料使用 `E:\txt`，尚不能认定 100% 采用。

## 本轮更新

- 快速聊天提供独立窗口与草稿，支持模型、项目、扩展、流式回复和 PDF；可置顶、收起、保存后隐藏，并在主工作台继续会话。[使用说明](QUICK-CHAT.md)
- MCP 资源与提示词中的 PDF 支持离线阅读、查找、导出和显式加入附件；模型仍只接收提取文本。[文件说明](MCP-BINARY-FILES.md)
- 工作台快照、事务返回值与备份改为逐条记录复制，降低整份序列化产生的临时分配峰值，保留完整数据和副本隔离。单条记录大小仍不受此修改限制。
- 工作台、快速聊天与 PDF 原件保存错误使用中文恢复提示，无效 Cron／时区也显示中文；未知服务错误保留原始诊断文字。
- 保留 PDF 阅读、停靠 HTML 预览、本地恢复副本和共享文字提示，以及开源许可证和原始版权声明。
