## 本轮更新

- PDF 导入保留原件，支持离线版式阅读、文字选择、目录定位、全文查找、链接、只读批注和原字节导出；完整备份可重建缺失原件。八种模型协议继续只发送提取文本。[阅读说明](PDF-PREVIEW.md)
- 自动恢复副本采用完整 gzip JSON，保留同步落盘、原子替换、精确恢复与旧版纯 JSON 副本。[恢复说明](LOCAL-RECOVERY.md)
- 安装验收同步要求停靠 HTML 预览与六组 PDF 检查。发布策略至少要求 229 项完整桌面检查，以及同一应用体的十一份匹配记录。
- Windows 流水线在完整包体与设置检查之后增加文字提示专项，覆盖新构建中的五处信息与六种主题／缩放组合；本地源码专项通过，托管和新分发包执行仍待完成。
