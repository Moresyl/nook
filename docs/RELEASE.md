## 本轮功能

MCP 资源与提示词的 PDF 现在可以离线阅读、查找、导出，并显式加入聊天附件。添加操作保留当前草稿与模型选择；保存失败可以重试，原件随备份和重启恢复。模型继续只接收提取文本。[MCP 文件说明](MCP-BINARY-FILES.md)

已有 PDF 阅读、停靠 HTML 预览、恢复副本和共享文字提示继续保留，详见[PDF 阅读](PDF-PREVIEW.md)、[项目预览](PROJECT-PREVIEW.md)与[本地恢复](LOCAL-RECOVERY.md)。开源许可证和原始版权声明保留。
