## 本轮修改

- 工具摘要继承对话字号，保留真实状态和耗时；运行／结束分别控制展开。完整输入与结果按原文复制，失败可重试，旧复制请求不覆盖新输出。自动收起先返回摘要焦点，主工作台与快速聊天共用；实际请求保留文本附件，展开动画不压缩原文面板。[工具记录](TOOL-ACTIVITIES.md)
- 自家主窗口和快速聊天的主文档恢复剪贴板写入；读取、子框架与非自家窗口继续拒绝。实际同地址非自家窗口与原生复制路径已验证。
- 安装版验收同步 283 项门槛及最新预览／分支／工具证据，继续要求包体一致、正常退出和保留数据的卸载。

- 项目本地分支可查找、创建与切换，使用 Git 的常规覆盖保护；工作树占用分支不能切换。更新文件树与干净文件，保留未保存草稿及原始比较基线，关闭该项目预览；钩子失败后显示真实分支状态。[项目分支](PROJECT-GIT.md)

- 文件标签自动显露选中项，支持方向键循环、Home／End 和安全关闭；窄编辑器使用带中文名称的 24px 图标操作。[窄窗原图](images/editor-tabs-dark-150.png)
- 项目文件保存失败显示中文恢复提示，保留草稿、标签和原文件，可重试保存并关闭。[失败状态原图](images/editor-tabs-save-failure.png)
- 主界面重载释放并排 HTML 预览，取消尚未完成的准备。重新打开保留编辑草稿并使用新会话；旧关闭请求不能影响替代视图。[HTML 预览](PROJECT-PREVIEW.md)
- 页面切换、窗口调整和缩放时保持侧栏选中项可见，页面导航标记当前页面。[设计对照](DESIGN-ALIGNMENT.md)
- 独立临时浏览器支持最多 16 页、独立历史／地址草稿、共享网站存储、后台失败恢复与原生新建／关闭／循环快捷键；切换页面保留网页与聊天草稿。[浏览器](BROWSER.md)
