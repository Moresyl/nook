- 会话任务步骤保留有效记录、工具原文和草稿；无效更新保留旧记录，停止后显示“待继续”，重启不会重放工具。
- 普通表单、共享按钮和紧凑选择器采用对应参考规格；设置搜索保留外层焦点圈，快速聊天标题保持 22px 紧凑高度。
- 代码块采用明暗代码表面、8px 圆角、对应内距与相对字号／行高。复制提供成功／失败反馈和等待锁定；原文变化或组件关闭后拒绝旧完成状态。
- 代码复制提示不计入聊天正文查找，真实代码仍精确高亮。原生测试先复现旧错误，再验证成功和失败提示均无匹配。
- 工作树只读身份查询按四项一批执行，独立 Git 元数据读取并行等待；删除保护、快照与源仓库复查保留。
