## 本轮更新

- 浏览器错误页区分 DNS、离线、连接拒绝、超时、证书和其他失败，提供主机说明、排查详情与重试；保留加载中编辑的网址草稿，并支持空白标签页崩溃后重建。矮窗口优先显示标题与原因，长详情和重试通过键盘滚动访问。侧栏隐藏的读屏播报文字保持在滚动容器内。

- 文件树可以复制磁盘上的 UTF-8 文件内容，保留 BOM、换行及空文件，沿用 256 KB 限制；读取或剪贴板失败可重试，切换目标后迟到的读取不会复制内容或关闭新菜单。

- 图片预览可在主窗口和快速聊天保存转换后的 JPEG，取消不写入，失败可重试；导出保留原附件、草稿及所选图片的字节。

- 文件树菜单新增完整路径复制与资源管理器定位，失败保留菜单和重试焦点；主进程限制现存项目条目的真实路径，旧菜单的延迟路径不会写入剪贴板。

- 最近聊天到达列表末尾时自动展开下一批，保留当前聊天、输入焦点与草稿，并保留键盘“显示更多”入口。

- 文件树支持在选定目录新建文件夹，重名或无效名称可修正后重试，创建时保留未保存的编辑草稿。

- 终端关闭等待真实退出回调再释放监听器；回调超时保留窗口和会话，迟到回调到达后允许重试退出，未完成进程继续计入会话上限。

- 文件树支持右键及键盘菜单，可直接打开、展开／收起、复制相对路径和在目标目录新建文件；复制失败可重试，旧请求不会干扰新菜单。

- 文件树启用虚拟滚动，保留分页、错误重试、祖先目录与跨视口键盘导航；千文件目录无需同时挂载全部条目。
- 文件树增加悬停淡显与键盘焦点父目录引导线，支持减少动画；极矮视口仍保持引导线与行对齐。
- 文件树改用单图标和紧凑缩进，移除八级缩进上限，深层目录继续区分层级。
- 预览分栏增加细渐变指示线、内侧焦点框、双击均分和拖动取消回滚；预览会话与草稿在拖动前后保留。
- 文件树滚动时保留展开的祖先目录，在子树末尾推离；键盘定位避开固定目录，矮窗口下编辑器空态说明保持可读。
- 紧凑侧栏的会话和操作按钮分开布局，修复高缩放时操作按钮拦截会话点击的问题。
- 文件树支持直接键入文件名前缀定位，重复首字母循环查找，自动滚动显示焦点。定位不会打开文件；输入法组词与确认键受到保护。
- 会话重命名共用同一对话框，固定操作目标，保存失败保留输入并回焦，提交期间防止重复请求与提前关闭。
- 会话菜单支持重命名、置顶、归档、导出与删除。导出取消保留菜单，写入失败可重试；删除当前会话会清理对应草稿并保留其他会话。
- 置顶会话可拖动或用键盘排序。最近聊天逐批展开，两组分别保存折叠状态，搜索选中的聊天自动显示。
