## 本轮更新

- 快速聊天提供独立窗口与草稿，支持模型、项目、扩展、流式回复和 PDF；可置顶、收起、保存后隐藏，并在主工作台继续会话。[使用说明](QUICK-CHAT.md)
- MCP 资源与提示词中的 PDF 支持离线阅读、查找、导出和显式加入附件；模型仍只接收提取文本。[文件说明](MCP-BINARY-FILES.md)
- 工作台快照、事务返回值与备份改为逐条记录复制，降低整份序列化产生的临时分配峰值，保留完整数据和副本隔离。单条记录大小仍不受此修改限制。
- 保留 PDF 阅读、停靠 HTML 预览、本地恢复副本和共享文字提示，以及开源许可证和原始版权声明。

大型备份和聊天验证已减少测试进程不使用的完整工作台回传，保留实际接口读取与原有内容、哈希、恢复和重启断言。这是验证传输的调整，不是所有原生渲染故障的根因结论。关闭超时现场的 JavaScript 清理已结束，原生等待原因仍需查明。

真实云服务、系统向导／选择器、物理输入、完整无障碍与目标平台仍需分别验收；本地协议服务、静默安装和测试替身仅证明各自范围。
