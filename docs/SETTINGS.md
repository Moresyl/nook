# 设置与草稿

打开设置，在侧栏搜索分类或字段。按 `Ctrl+F` 聚焦搜索，用方向键选择结果，回车定位对应控件；没有匹配时，当前表单仍保留。

模型连接、桌面快捷键、工作树路径与保留数量、MCP、插件权限和记忆支持未保存更改保护。切换分类可继续填写其他表单，再返回原草稿。

关闭设置、取消编辑或从设置进入其他功能时，如果相关表单尚未保存，会显示「放弃未保存的更改？」：

- **继续编辑**：返回表单，保留输入。默认选中此操作，回车和 Escape 都不会放弃草稿。
- **放弃更改**：放弃提示涉及的草稿，执行刚才的离开操作。返回模型连接列表只放弃该连接；关闭整个设置涉及本次打开的所有未保存表单。

保存进行中时，相关控件与离开入口暂时不可用。保存失败会显示错误并保留输入，可修改后重试。将字段恢复原值后，不再提示有未保存更改。

草稿只在本次打开设置期间保留。明确放弃或关闭设置后，不会自动恢复未保存的内容；需要长期保留的更改请使用对应保存操作。
