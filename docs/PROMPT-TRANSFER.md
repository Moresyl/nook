# 提示模板导入与导出

在 **助手 → 提示模板** 中，点击某个模板右侧的 **导出**，或点击页面上方的 **导出全部模板**。可以保存为 JSON 或 gzip 压缩的 JSON。文件包含完整模板、变量说明、默认值、下拉选项和关联助手配置；多个模板共享同一个助手时，只导出一份助手配置。工作区标识和连接凭据不会加入文件。

点击 **导入模板** 后，先在 **查看模板** 中逐项检查模板内容、变量设置和助手工作指令。预览保留原始文本。点击 **添加** 才会创建模板和关联助手的独立副本；同名原有内容会保留。取消或按 Escape 可退出预览，焦点回到导入按钮。

导入不会发送模型请求、追加草稿或更换当前助手。之后仍需自行选择模板、填写变量，再点击 **追加到草稿**。写入失败会保留完整预览及当前选择，修复磁盘问题后可以重试。

文件支持按内容识别 JSON／gzip，解压后的完整数据最多 4 MB。模板库最多 200 个模板，助手总数最多 1,000 个。只有被模板引用的助手配置才允许进入分享文件。工作台的完整备份及恢复也会保留导入后的关联和变量设置。

本机最终源代码通过 660 项／64 个文件测试、类型检查、构建、五项独立传输检查和完整 215 项 Electron 检查，并正常关闭。六张本轮截图已逐张核对，包括浅色预览／写入错误，以及深色最小窗口 100／125／150% 缩放、键盘焦点与 Escape。见 [源代码验收证据](../verification/prompt-transfer-review-result.json)。发布策略要求新的完整 215 项匹配应用主体；此前 210 项安装证据保留自己的哈希，不能满足新策略。本轮安装、完整远端验收、其他工具格式互通、物理系统文件选择器及更广的平台检查仍待完成。
