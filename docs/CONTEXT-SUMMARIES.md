# 会话上下文

长对话可以生成摘要，让后续请求携带摘要与近期消息。完整消息、附件、工具记录和回复版本仍保留在聊天历史中；摘要不会删除原文。

在已有聊天的输入框下方打开「管理会话上下文」，选择摘要模型和保留的最近轮数，再生成预览。检查并编辑摘要后，点击「保存并使用摘要」。生成预览本身不会改变会话上下文。

轮数按完整用户提问与对应回复计算。保留 0 轮表示概括全部已完成消息，最多可保留 20 轮。每段会话最多保存 20 个摘要；可以选择历史摘要，恢复完整上下文，或删除未使用的摘要。

较早的消息、附件或工具结果发生变化后，旧摘要会失效。再次发送时使用完整上下文，不继续使用过期摘要。正常追加消息不会使原文未变的摘要失效。分支、重试和模型比较也会检查各自的原文范围。

摘要生成会把覆盖范围内的原文与附件发送给所选模型，产生一次模型请求。它不使用项目工具、MCP 或插件。可以停止生成；请求失败、停止或保存失败时，不会覆盖现有摘要和完整历史。用量按钮显示服务实际返回的统计；未返回的数据不按零计算，也不能作为最终账单。

摘要可能遗漏细节。需要原始信息时，可以恢复完整上下文。当前单次摘要原文请求限制为 4 MB，摘要文字限制为 256,000 个字符；模型自身的输入容量可能更小，服务拒绝过长请求时应保留更多近期轮次或缩短来源。当前不自动分段概括，也不自动触发压缩。

普通聊天的摘要和原文随工作区保存；临时聊天仍遵循退出后清除、不进入备份的规则。快速聊天使用同一段会话当前有效的摘要，管理摘要仍在主工作台进行。

类型、构建、单元回归与源码桌面专项已通过；包含最小窗口的明暗主题、三档页面缩放及快速聊天。最终完整桌面、安装包和流水线验收仍在继续。上一批安装包的通过记录不能证明这次新增能力。
