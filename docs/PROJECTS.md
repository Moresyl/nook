# 项目文件与编辑

长文件树按可见区域渲染，滚动时逐步显示其他条目。已加载的文件仍可用方向键、Home／End 或文件名前缀定位；跨越屏幕范围时自动显示目标行，分页、目录错误和未保存草稿继续保留。千文件目录的实际分页与键盘验收见[虚拟滚动记录](../verification/tree-windowing-review-result.json)。

展开长目录后，祖先目录会停留在文件树顶部，并在子树结束时随内容移走。点击悬停的目录可折叠，方向键与「定位当前文件」会让目标行避开目录标题。窄窗口优先保留焦点文件的可见空间；没有打开文件时，编辑器仍显示完整的操作说明。

文件树获得焦点后，可以直接键入文件名开头来定位。连续输入细化匹配，重复首字母循环查找；停顿 700ms、离开文件树或使用方向键后重新开始。定位只移动焦点并滚动到对应行，按 Enter 才打开文件。匹配忽略大小写，只覆盖当前已加载且展开的条目；需要跨目录查找时使用路径搜索框。

查找文件时，“刷新文件”保留查询并重新读取匹配路径；新文件保存到磁盘后自动更新结果。“定位当前文件”清空查找、显示文件树并聚焦正在编辑的文件。清除查询不触发额外定位，目录错误仍保留明确的重试入口。[工具栏联动验收](../verification/file-search-toolbar-review-result.json)

项目 Git 面板支持查找、创建、切换、重命名和安全删除本地分支，保留未保存草稿，并刷新文件树和干净文件。操作保护与使用范围见[项目分支](PROJECT-GIT.md)。

可创建独立 Git 工作树，并添加为另一个项目。创建保留原项目分支、暂存区、文件改动、草稿与预览，项目登记失败可单独重试。使用方法与验证范围见[独立工作树](PROJECT-WORKTREES.md)。

「设置 → 工作树」集中列出已登记项目的实际工作树和关联会话，可直接打开会话或选中项目新建聊天。切换保存未发送草稿和附件；保存失败留在当前窗口供重试。

HTML 文件现在可从编辑器直接预览当前草稿，在独立窗口运行项目内的网页资源。使用方法、资源范围和验证边界见 [HTML 预览](PROJECT-PREVIEW.md)。

项目页把文件树、代码编辑、Git 审阅和终端放在同一个工作区。文件树逐级展开已有目录，目录排在文件前面；点击文件会在本地 Monaco 编辑器中打开标签。文件树使用用户指定的界面规范中的中性色、紧凑控件、语义图标和键盘焦点样式。

文件树上方的「查找文件路径…」按项目内相对路径查找文件，支持中文、忽略大小写，并接受 `/` 或 `\` 分隔符。输入后显示结果；↑／↓、Home／End 选择，Enter 打开，Escape 或清除按钮返回原文件树。输入法组词期间的回车不会打开文件。打开结果沿用已有编辑器，未保存草稿保留，搜索不会读取文件正文、写入项目或请求模型。

每次最多显示100个结果、遍历10000个目录条目；达到上限会提示结果不完整，缩小关键词后可继续查找。无法读取的子目录会明确提示，项目根目录读取失败可重试。只查当前项目，排除内部目录和目录链接；不会将链接指向的项目外文件加入结果。查询变化后丢弃旧结果，请求按顺序执行，清空查询会保留原树的展开状态。

项目较多时，顶部项目列表可横向滚动，新增按钮固定在列表外。选择项目或调整窗口会显示当前项目；键盘正在浏览其他项目时优先保留焦点所在行，手动横向滚动不会自动跳回。项目按钮显示选中状态，悬停或聚焦可查看完整名称。

此项源码修正通过类型、构建及七组真实桌面项目检查，覆盖额外六个长名称项目、100%／125%／150% 缩放、键盘设置返回、草稿保留和真实终端；最终正常退出用时 2455ms。已查看[浅色列表](images/project-switcher-light.png)和[深色窄窗口](images/project-switcher-dark-narrow.png)。首轮高度失败已修正；第二轮全部组完成后退出超时，第三轮正常退出，原超时原因仍未证实。详见[前轮记录](../verification/project-switcher-review-result.json)，该批的旧安装候选不包含此修改；后续 `c81b8c38` 候选已包含该提交，分发范围见[发布状态](RELEASE.md)。

文件和改动按钮旁的文件夹按钮可以“隐藏文件树”或“显示文件树”，支持 Enter 和空格。隐藏只收起面板，保留目录缓存、展开状态和文件草稿；恢复时继续使用原来的文件树。切换到审阅面板时该按钮停用，返回文件面板后恢复。命令面板提供相同的文件树、终端和审阅切换，状态与工具栏同步。在同一窗口内离开并返回项目页会保留面板选择；重启后默认显示文件树、关闭终端并进入文件面板。目录缓存随文件树实例释放，返回页面后按已保存草稿重新定位文件。

每个目录分批读取，每批最多 200 项。“加载更多”显示已加载数量和目录总数，继续读取剩余项。原来的 2,000 项截断已移除。分页绑定当前目录清单的版本；两次读取之间新增、删除或重命名条目时，后续页会被拒绝，已有内容保留。点击“重试”重新读取第一批，再继续加载。单纯修改文件内容不会改变目录清单版本。

“刷新文件”更新根目录与当前可见的展开目录，并重新读取之前已加载的页数范围。“收起所有目录”折叠目录；“定位当前文件”读取所需的祖先目录并定位正在编辑的文件。展开结果按项目独立保留在当前文件树实例内，切换项目后过期的读取结果不会替换新的目录。展开状态不作为工作台持久化设置；重启时根据恢复的文件草稿重新展开祖先目录。

| 按键 | 文件树操作 |
| --- | --- |
| ↑ / ↓ | 移动到上一个或下一个可见条目 |
| Home / End | 移动到第一个或最后一个可见条目 |
| → | 展开目录；已展开时移到第一个子项 |
| ← | 收起展开的目录；其他情况下移到可见父目录 |
| Enter / 空格 | 展开或收起目录，或打开文件 |

“新建文件”预填最后选中文件所在的目录或选中的文件夹。父目录需要已经存在，磁盘文件在第一次保存时创建。读取目录、展开、刷新、切换项目和定位文件都不会把编辑器草稿写入项目文件；保存继续使用文件版本比较，防止覆盖其他操作的改动。

右键点击文件或目录，或聚焦条目后按 Shift+F10／菜单键，可打开文件操作菜单：打开文件、展开或收起目录、复制相对或完整路径、在文件资源管理器中显示，以及在对应目录新建文件或文件夹。方向键和 Home／End 切换菜单项，Esc 返回原条目；滚动文件树会关闭菜单。复制或定位失败保留菜单和重试焦点，切换目标后旧路径请求不会复制内容或关闭新菜单。

完整路径和资源管理器定位由主进程解析现存文件或目录的真实路径，重新检查所属项目，并拒绝项目外路径、内部目录及直接链接。操作不会读取正文，因此二进制和超过编辑器大小限制的文件也可复制路径或定位。资源管理器接口只确认调用已发出，窗口是否实际打开和选中仍取决于系统。

文件访问沿用项目根目录的真实路径校验。文件树排除 `.git`、`node_modules` 和符号链接／Windows junction，不能借目录链接读取项目外文件。其他隐藏文件仍可在编辑器中显示；模型工具的敏感文件排除规则独立生效。编辑器只打开不超过 256 KB 的 UTF-8 文本，保留 UTF-8 BOM，拒绝二进制和无效编码。

文件树按需缓存目录，合并重复请求，并丢弃失效的读取结果。目录分页和文件树生命周期单元检查覆盖真实 2,005 项目录、排序、边界、版本变化、加载失败、刷新、请求去重、键盘选择、定位与离开项目后的过期响应。

较长的项目名称和目录路径保持单行，悬停可查看完整文字，项目设置中也保留完整路径。短窗口压缩留白，较矮的窗口合并文件标签与保存栏，并把添加项目入口移到项目列表。使用 760×540 实际窗口、默认终端尺寸和 100%／125%／150% Electron 缩放时，主侧栏保持显示，125%／150% 手动收起文件树；三档都验证了可见代码输入和真实终端命令，编辑画布均至少 60 CSS 像素，终端完整留在窗口内。150% 下的项目设置保留完整名称、路径和 Esc 后的焦点。缩放截图通过 Electron 原生捕获并检查完整内容尺寸。
