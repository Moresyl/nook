# 工作台备份

在“设置 → 数据与备份”选择“导出备份”，默认文件为 `Nook-backup-日期.json.gz`。系统保存对话框也提供普通 `.json` 选项。两种文件包含相同的完整工作台数据；gzip 压缩不提供加密。恢复时按实际文件内容识别格式，因此已有 JSON 备份、带 UTF-8 BOM 的 JSON 和改名后的 gzip JSON 也可读取。

保存格式由最终文件名决定：以 `.gz` 结尾时压缩，使用 `.json` 文件名时保存普通 JSON。要导出普通 JSON，请在保存对话框中将文件名改为 `.json`。

备份包含普通对话、附件、草稿及其选择、项目配置、助手、资料集、向量索引、对话来源快照、自动任务配置和执行记录，以及已导入技能／插件的完整文件和插件自身数据。临时聊天及其附件、草稿、分支和回复版本不进入备份，见 [保存范围](TEMPORARY-CHATS.md)。项目配置包含目录位置，备份不复制项目目录及外部模型运行时。配置的 API 密钥、MCP 静态凭据和 OAuth 登录数据不进入备份；同一目标地址已有的本地凭据按现有绑定规则继续使用。

JSON 正文的 UTF-8 编码上限为 256 MB，gzip 文件上限为 64 MB；普通 JSON 文件同样最多 256 MB。导出检查实际生成的完整内容，超限会明确失败，不丢弃消息、附件或索引来凑大小。解压过程分别限制文件输入和展开内容，防止压缩文件绕过正文上限。单个附件、草稿、资料库及扩展包各自的限制仍然适用。

导出按 JSON 值分段编码并进行流式压缩，先写到目的文件旁的随机临时文件，完成后刷新并关闭文件，再原子替换目的文件。编码、压缩、写入、刷新或替换失败时，已有目的文件保持原样；临时文件会尝试清理。Windows 短暂文件共享冲突采用有上限的重试。若系统连临时文件删除都拒绝，报告原保存失败，不会用清理错误覆盖它。

恢复先完整读取、检查 gzip 校验和与 UTF-8、解析 JSON 并校验工作台结构，然后显示替换确认。取消确认或读取失败不修改当前工作台。确认后保存旧工作台的本地回退文件，停止相关后台运行时，并验证与恢复扩展资产。技能和插件使用新目录 ID，聊天／草稿／自动任务中的选择随之映射；恢复的插件默认关闭且没有授权，MCP 自动连接关闭，导入的自动任务计划全部暂停。流程与回退边界见 [本地扩展文档](PLUGINS.md) 和 [自动任务文档](AUTOMATIONS.md)。

托盘、关闭窗口后保持运行及全局快捷键在恢复后全部停用，已有入口会释放，快捷键组合保留。确认配置后可主动重新启用，规则见 [桌面入口文档](DESKTOP-INTEGRATION.md)。

完整备份也包含助手配置及其工作指令。只分享助手时可使用独立导出，文件不包含模型连接、对话和密钥，导入创建新的助手 ID；见 [助手配置文档](ASSISTANTS.md)。

提示模板作为独立工作台记录随完整备份保存，恢复保留模板 ID、内容和变量标记。已经展开的消息与草稿保存实际文本；旧备份没有模板字段时恢复为空列表，见 [提示模板文档](PROMPT-TEMPLATES.md)。

重新生成的回复版本、各自的归档／后续对话、完整工具与用量记录、独立草稿随完整备份保存，恢复保留版本关系与编号，见 [回复版本文档](REPLY-VERSIONS.md)。

各条消息的编辑草稿、手动编辑标记及完整的编辑前归档随完整备份保存；编辑输入未能保存时会阻止导出，导入验证会拒绝超出编辑草稿 UTF-8 总额或指向不存在消息的草稿，见 [消息编辑文档](MESSAGE-EDITS.md)。

处理备份时界面显示状态并禁用重复操作；文件服务只运行一个任务。文件处理有 60 秒截止时间，退出应用会取消文件处理任务，并等待文件资源释放。取消在替换开始前被检查；已经完成的原子替换不会被回滚。当前不提供分卷、远程同步、加密备份或通用 JSON 数据库恢复。

验证覆盖普通／压缩往返、Unicode 与转义字符、旧备份、精确字节上限、文件增长、解压超限、CRC／截断／无效 UTF-8、短写入、零字节写入、磁盘与清理错误、保存最后阶段的取消、阻塞读取取消及关闭状态。真实 Electron 检查使用超过旧 64 MB 上限的 Unicode 对话备份，比较完整消息哈希，验证普通 JSON 导入、gzip 导出与恢复、取消替换、真实文件系统失败、损坏拒绝、重启和浅色／深色最小窗口界面。测试文件与系统对话框边界位于隔离测试目录；最大 256 MB 规模、跨平台及安装器审计仍需单独验证。
