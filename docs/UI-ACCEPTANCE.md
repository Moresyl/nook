## 验收规则

- 对照选择器、主题层叠、窗口类型与真实调用参数，再核对最终 computed style；不从组件名称猜测默认规格。
- 覆盖实际支持的默认、悬停、按下、键盘焦点、禁用、选中、错误与等待状态；明暗主题分别检查。
- 检查最小窗口、长内容、应用缩放、独立滚动、键盘回焦和减少动画设置；浮层操作保持可见。
- 精确尺寸原生套件保留设备缩放 1 的既有夹具；实际系统 DPI 另行核对，不能混为同一证据。
- 用同一最终应用体分别执行源码、包内和实际安装回归，保留真实退出、失败现场、原始截图与法律文件。

原始发布门槛、各模块行为和卸载数据保留要求继续适用，见[完整交付要求](DELIVERY.md)。历史测试只能证明其准确源码和产物，不能代替当前应用体。
