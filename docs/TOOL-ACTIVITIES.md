# Nook 工具记录

## 任务步骤记录

项目的分析计划与执行模式支持记录任务步骤。记录包含待办、进行中与完成标记，同一时刻最多标记一个进行中的步骤；完成数量显示为“标记完成”，实际结果仍需核对工具输出或验证记录。停止或结束回复后，未结束的步骤显示“待继续”。

最新有效记录展示在原始工具活动上方；更新失败保留上一份有效记录。步骤文字按原文显示，最多 20 项，每项不超过 300 字符，说明不超过 2,000 字符。记录保存在会话工具历史中，重启后保留；记录本身不会执行步骤或写入项目计划文件。

新类型与完整覆盖率验证通过 136 文件／1,602 项测试，原 80% 门槛保持不变；沿用已验证且匹配当前包的 `71fc205` 编译应用体。8 组真实桌面检查覆盖读取与步骤更新、原文键盘展开、无效更新、停止及重启；两主题、两种尺寸和三档缩放共 12 种布局，每一步可滚动至可读区域。完整源码、包内与实际安装各通过 383 项／75 次正常退出，无强制结束；三轮任务步骤原图各 16 张逐张复核，包含 760×540／150% 缩放下的最后步骤。每轮 40 份报告与 633 张原图归档，未全部视觉复核。原五项分发专项、十一份匹配运行记录和保留数据卸载通过；首次预览超时保留，原因未确认。设备缩放 1 的精确尺寸夹具不代替实际系统 DPI 与物理输入。[专项测试](../verification/task-plan-focused-review-result.json) · [新完整单元验证](../verification/task-plan-final-validation-review-result.json) · [原生专项](../verification/task-plan-native-review-result.json) · [三轮与分发](../verification/task-plan-runtime-review-result.json)

## 原始工具活动

对话中的工具记录先显示操作、相关路径或查询、真实状态和已结束的耗时。运行中的详情默认展开；运行结束后默认收起。你在执行中和结束后的展开选择分别保留，输出更新不会重新展开手动收起的记录。

点击摘要、按 Enter 或空格可查看完整输入和结果。长文本在详情内滚动，输入与结果各有复制按钮；复制失败可以重试。显示和传给剪贴板的字符串保留原文，不解析或重排 JSON，大整数、重复键和文字形式的 HTML 均保持原样。Windows 系统剪贴板会按平台惯例使用 CRLF 换行。

主工作台与快速聊天使用同一组件，各自保存当前展开选择。重启后，记录的输入、结果、状态与时间戳保留，已结束的记录恢复默认收起。审批仍通过原有审批窗口进行。自动收起时，详情中的键盘焦点先返回摘要，随后隐藏内容退出键盘操作范围。

## 设计与验证

参考为 `E:\txt` 的 26.930.41038／build 13022。已核对工具活动标签、展开控件及其实际调用条件：摘要采用当前对话字号、4px 间隔和单行省略；支持时使用文本颜色 60% 的 oklab 混合；详情缩进 24px，上下 8px／4px、块间距 8px；过渡为 300ms、cubic-bezier(.19, 1, .22, 1)，减少动效时关闭过渡。

状态标签、耗时、复制按钮、原文代码块和 CSS grid 动画为独立实现选择，不能据此声称整套界面 100% 还原。只解释已知原生工具的参数，外部工具保留其显示名称。

39 项工具摘要／状态和权限专项单元测试通过，统计模块覆盖率 100%；另外 4 项请求夹具回归验证追加附件和多模态文本的识别。8 组真实桌面专项覆盖审批拒绝、运行、停止与完成、流式输出、复制失败重试和旧复制请求、焦点交接、受限快速聊天、明暗主题及 100%／125%／150% 缩放、减少动效和实际重启。三个真实审批／执行请求均保留导入的文本附件；展开过程中原文面板与动画结束后的自然高度一致。9 张最终原生截图逐张检查；使用固定设备缩放和脚本输入，不代替真实系统 DPI、物理辅助技术、真实云服务或最终分发验收。[验证记录](../verification/tool-activities-review-result.json)
