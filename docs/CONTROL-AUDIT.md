## 已确认或需要测量的差异

| 控件／状态 | 参考要求 | 当前源码与下一步 |
| --- | --- | --- |
| 键盘焦点 | 浅色 `#0169cc`、深色 `#0285ff`，采用 `--color-ring` | 全局、工具摘要、开关与文件树仍用 `--ds-accent`；深色为 `#339cff`，需要统一焦点语义变量 |
| 输入悬停边框 | 浅色黑 25%、深色白 30% | 当前将正文色混合 25%，色值与深色透明度均不同 |
| 输入／选择聚焦边框 | `--alpha-50` | 当前蓝色边框加 1px 蓝色阴影；需采用参考边框并检查可见性 |
| 非法输入 | 浅色 red-500、深色 red-600 | 部分字段已有 `aria-invalid`，共享样式缺少对应状态；需验证错误与聚焦优先级 |
| 默认按钮尺寸 | 20px 高、12px 字、默认 gap 3px、gutter 6px | 当前只有 min-height 20px，另有垂直 padding 与行高；gap 6px、gutter 8px。先测真实高度，再区分默认、图标、导航和较大按钮 |
| 按下状态 | ghost／solid 各自具备 active 色 | 当前共享按钮有 hover，未独立定义 active；需从原始 CSS 确认变体，不将单个默认变量应用于所有按钮 |
| 选择器触发器 | gutter 6px、gap 4px、ghost 背景 | 当前继承输入的 8px、gap 6px、透明背景；需同时检查输入区中的紧凑变体 |
| 选择器列表 | 16px 外圆角、14px 字；参考菜单 gutter 6px | 当前列表外 padding 4px，部分选中／悬停色仍采用通用 ghost；需核对变体级 CSS |
| 开关开启状态 | `--color-background-info-solid`，默认变量指向 blue-400 | 当前使用随主题变化的 `--ds-accent`；需确认参考主题覆盖后再修正 |
| 弹窗边距与位置 | 宽上限 `100vw/zoom - 32px`，高上限 `100dvh/zoom - 40px`，位置随可用高度计算 | 当前为 `100vw - 40px`、`100dvh - 80px` 与固定上移 20px；现有窄屏布局可用，但并非相同公式 |
| 字体、图标、原生提示 | 参考字体、线性图标、工具提示规格 | 使用合法 Inter／系统中文与独立图标，部分 tooltip 为原生 title；差异继续明示 |
