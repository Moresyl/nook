# 快速聊天

点击工作台顶部的「快速聊天」，打开独立的小窗口。可以输入问题、选择模型、添加文档或图片，也可以继续已有聊天。模型连接与项目配置沿用工作台设置。

## 窗口与草稿

顶部提供新聊天、在工作台中打开、置顶、收起和隐藏操作。Escape 保存输入后隐藏窗口；再次打开会恢复输入。窗口关闭按钮同样隐藏窗口。工作台退出时会保存两个窗口的输入；保存失败时保留窗口并提示重试。

快速聊天的新聊天及每个会话分别保存草稿，与主工作台的输入分开。「在工作台中打开」进入同一已保存会话，不会自动发送或消耗快速聊天的未发送输入。快速聊天使用近期会话列表；完整历史管理、消息编辑、分支和模型比较在主工作台完成。

在「设置 → 外观与交互 → 桌面入口」启用全局快捷键后，可选择打开工作台或快速聊天。已有设置默认继续打开工作台；快捷键被其他程序占用时需要改用其他组合。应用运行期间才响应全局快捷键。

## 附件与执行

PDF 附件可以查看原始页面、目录、查找和只读批注，或导出原始字节。原件随完整工作台备份保存；模型请求仍只发送提取文本。图片、文档提取和大小限制沿用[附件规则](ATTACHMENTS.md)。

执行模式继续使用项目范围和具体操作审批。快速聊天只显示并处理当前会话的审批，停止按钮只停止当前会话。模型请求发送到所选服务；独立窗口不改变服务的数据处理方式。

## 保存与恢复

输入自动保存。磁盘错误时保留当前输入和此前已保存版本；检查磁盘空间与目录权限后重试隐藏或发送。完整备份恢复会更新草稿版本，旧版本的发送请求会被拒绝。若恢复时仍有未保存输入，先复制输入，再重新打开窗口，避免覆盖恢复后的记录。

快速聊天使用独立的受限预加载桥接，不提供主工作台的任意文件、终端、设置修改或完整备份接口。原件阅读仅允许当前快速聊天草稿或会话中引用的文件。

源码实现已接入；真实桌面、分发包与托管发布的当前验证状态见[发布状态](RELEASE.md)。本地测试服务与被替代的系统选择窗口不代表真实模型质量、物理全局键盘事件或跨平台验收。
