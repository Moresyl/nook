# 长对话导航与查找

侧栏“最近聊天”先显示 10 条，列表末尾进入视口时自动展开下一批 10 条，不切换聊天、不移动输入焦点，也不消费草稿。当前聊天超出首批时仍单独保留；置顶聊天独立显示。键盘可继续使用“显示更多”，激活后聚焦首个新增聊天。分组折叠时停止自动展开，旧观察回调在清理后失效。此功能逐批显示已载入本地工作台的聊天，不代表后端分页或列表虚拟化。

自动展开通过 9 项观察生命周期单元检查；同一候选的源码、包内和实际安装完整回归各通过 412 项，其中各包含 5 项导航检查及明暗主题、760×540 窗口和三档缩放的实际滚轮操作。此前六张源码专项原图逐张查看，本次完整回归另抽查八张代表截图；未逐张审阅全部截图。完整设计对齐与物理辅助技术仍待验收。[完整分发证据](../verification/sidebar-pagination-distribution-review-result.json) · [前期自动分页专项](../verification/sidebar-pagination-review-result.json)

窗口恢复显示时重新观察末尾，完成加载或组件清理时移除监听器。真实窗口隐藏／显示后的分页与焦点已验证；CDP 连接仍模拟渲染器可见性，因此 `visibilitychange` 的恢复路径由隔离单元夹具验证，不能称为实际页面可见性事件验收。

聊天左侧的细线导航轨按用户消息的顺序排列。悬停或键盘聚焦显示文字预览，点击或拖动定位到对应回合；导航轨聚焦时，`↑`／`↓` 移动焦点，`Home`／`End` 选择首尾，`Enter`／空格定位。预览最多 160 个 UTF-16 单元，不截断消息原文或拆开表情字符；只有附件的消息显示附件名称。滚动区域根据实际位置显示顶部与底部渐隐。

按 `Ctrl F`、点击聊天顶部的查找入口，或在命令面板选择“查找当前聊天”，打开正文查找条。输入关键词后定位到首个结果，`Enter`／`Shift Enter` 或上下按钮循环定位后续／前一个结果。`Esc` 或关闭按钮收起查找并恢复原输入位置。

查找按字面量、忽略大小写匹配，最多 512 个字符，支持跨行内 Markdown 格式的文字和代码块。代码块中的结果会同时调整代码块与聊天的滚动位置。图表切换为源码后更新正文索引，收起源码后移除对应结果；编辑输入草稿和更新滚动状态保留现有代码节点。标题、附件名称、工具记录和隐藏的数学辅助内容不作为消息正文参与查找；用户输入的 HTML 和正则符号始终作为文字。高亮使用浏览器文字范围，不改写消息内容。

查找不发送模型请求，不消费草稿或附件。回复生成期间继续更新结果，并保留当前匹配和手动阅读位置。离开当前聊天或重启应用会清除查找条、关键词和高亮，已有历史与草稿仍按原流程保存。“查找当前聊天”命令绑定实际显示的聊天，其他页面或聊天已删除时不可用。

导航轨的 26 × 2 像素标记、默认与邻近展开宽度、160 毫秒动效和滚动渐隐采用指定 UI 参考中的样式参数，以独立组件实现。减少动态效果时取消标记动画和跳转平滑滚动。同组对话的层级浏览、搜索、分页和切换见 [对话分支文档](CONVERSATION-BRANCHES.md)；临时聊天及并行模型比较仍待实现。

24 项导航与命令目录单元检查通过，相关合同代码的行、分支、函数和语句覆盖率均为 100%。五项真实 Electron 检查覆盖键盘、指针拖动、代码块溢出定位、草稿修改后的节点保留、图表源码的动态索引、实际 HTTP 流式生成及正常退出／重启，见 [开发运行时记录](../verification/chat-navigation-result.json)。
