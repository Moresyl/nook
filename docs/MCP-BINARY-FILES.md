# MCP 文件

在设置的 MCP「资源与提示词」中读取内容后，可以查看文本、预览支持的文件，或选择位置导出原始字节。读取和预览不会发送模型请求。

| 内容 | 可用操作 |
| --- | --- |
| 文本 | 预览；点击「用于对话」追加到当前草稿 |
| PDF | 阅读原始页面、目录和全文搜索；导出原件；点击「添加到聊天」作为附件使用 |
| PNG、JPEG、WebP、GIF | 查看规范化图片；导出原始文件 |
| SVG、音频及其他文件 | 导出后使用本机应用查看 |

## PDF 加入聊天

PDF 可来自资源或提示词。「预览文档」打开现有 PDF 阅读器，支持页面与提取文本切换、缩放、文字选择、目录、搜索和只读批注。预览本身不写入聊天历史。

「添加到聊天」保留当前消息、附件和模型选择，保存成功后返回消息框。保存失败时保留草稿和设置窗口，可重试；同一 PDF 的保存重试不会重复增加附件。原件随普通聊天草稿、历史及完整备份保存，模型只接收提取文本。临时聊天继续遵守其内存保存规则。阅读细节与格式边界见 [PDF 阅读](PDF-PREVIEW.md)。

## 限制与操作

单个 MCP 文件上限 2 MB，每次内容最多 12 项、合计 12 MB；每条消息最多 12 个附件。损坏 PDF 或图片可重试，错误不会显示远端敏感详情。空文件可导出，取消保存不写文件。HTML、脚本和资源链接按原文显示。

切换资源、提示词参数、分类、服务器或连接状态，以及订阅内容更新时，会关闭旧文件预览并忽略旧操作结果。Escape 先关闭当前浮层；关闭阅读器后回到文件入口，底层设置保留。

## 验证范围

当前 PDF 源码专项与失败记录见 [MCP PDF 验收](../verification/mcp-pdf-review-result.json)。新功能仍需完成同一应用体、安装与托管发布验收；原生保存窗口响应属于隔离测试夹具。整体状态见 [发布状态](RELEASE.md)。

早期图片、音频和二进制文件的 [源码记录](../verification/mcp-binary-files-review-result.json) 与 [分发记录](../verification/mcp-binary-files-distribution-result.json) 对应其各自历史版本，不能替代当前版本验证。
