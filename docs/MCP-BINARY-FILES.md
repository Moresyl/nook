# MCP 二进制资源与提示词文件

资源和提示词可返回文件、图片或音频。内容预览按项展示来源、媒体类型和字节数；用户可以导出原始文件，PNG、JPEG、WebP、GIF 可以打开图片预览。SVG、音频及其他文件通过导出查看。服务器返回的 HTML、脚本和资源链接作为原文显示。

图片预览复用附件解析工作线程的大小、像素和内存限制，显示规范化 JPEG 副本及转换说明。导出通过本机保存窗口选择位置，保留服务器返回的原始字节；空文件可导出，取消不写文件。无效编码、媒体类型或 URI 不产生可导出的快照。单项上限 2 MB，单次最多 12 项、合计 12 MB；失败可重试，错误不显示远端敏感详情。

加载和预览不会改写聊天草稿或发送模型请求。“用于对话”只添加当前文本，可在消息框中修改。模型工具读取资源或提示词时仍需现有具体请求授权；其结果只包含文本和二进制元数据，不包含文件编码。二进制预览和提示词内容不写入工作区历史。

切换资源、提示词参数、分类或服务器，以及连接失效后，旧操作不能替换当前选择或重新打开旧图片。关闭图片预览后仍留在底层设置窗口；Escape 只关闭当前最上层弹窗。正常重启保留原有草稿和服务器配置，连接恢复仍遵循原有连接规则。
