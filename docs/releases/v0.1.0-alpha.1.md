## 新功能

- 本地 AI 工作台：流式对话、消息编辑、回复版本、分支，以及 2–4 个模型的回复比较。
- 项目文件树、代码编辑与草稿恢复、Git 差异／暂存／提交、交互终端和 HTML 预览。
- MCP 工具、资源和提示词，助手、变量提示模板、知识资料库与隔离插件。
- 一次、周期及 Cron 自动任务；新增状态筛选、组合搜索，以及到期一次计划的“重新安排”。

## 变更与安全

- 保留原始开源许可证、依赖声明和分发所需的来源材料。
- 凭据使用系统加密；模型请求发往用户配置的服务。临时网页使用独立会话，工具访问保留具体审批。
- 增加 macOS Intel／Apple Silicon 与 Linux x64／ARM64 的原生构建入口；仅构建成功的文件才会上传，流水线入口不等于平台已验证。
- 应用源码固定于本标签 `f756ea4`；跨平台构建另外采用主分支中的测试平台模拟修正与许可证补充，不改应用源码、不移动发布标签。来源、下载哈希与各平台测试统计见 [构建校验记录](https://github.com/Moresyl/nook/releases/download/v0.1.0-alpha.1/release-verification.json)，Linux 最终构建见 [成功流水线](https://github.com/Moresyl/nook/actions/runs/41577173425)。

## 修复与体验

- 浏览器错误页区分离线、DNS、证书、超时等原因，并保留地址草稿及重试入口。
- 文件树支持键盘导航、虚拟滚动、复制路径／内容和新建文件夹；长内容、表格与代码支持滚动及复制。
- 终端清理等待退出回调；未完成时保留窗口并允许重试。

## 安装与已知问题

- Windows x64：下载 `Nook-Windows-0.1.0-alpha.1-x64.zip`，完整解压后运行文件夹内的 `Nook.exe`。不要只移动 EXE，旁边的资源与许可证文件必须保留。
- macOS：按 Intel／Apple Silicon 选择对应文件，打开 DMG 后把 Nook.app 放入应用程序文件夹，或完整解压 ZIP。Linux：AppImage 需要执行权限；DEB 适用于 Debian／Ubuntu 系统。
- 每个平台均提供 SHA-256 清单；应用源码 ZIP 与原生构建源码 ZIP 分开保留。下载和原生测试汇总见 `release-verification.json`。
- 本版本未签名／未公证。不要用它保存唯一一份重要数据，升级前请备份工作台。
- 已知间歇性退出超时仍未修复。最近一次匹配包的完整回归通过 262 项、29 次正常退出后，在模型比较恢复重启处超过 10 秒限制而失败；不宣称完整验收通过。1818 项单元测试与多项专项通过，仅证明相应范围。
- 本标签的新 Windows 托管流水线通过了类型／单元覆盖率及安装器打包检查，但完整桌面测试在表格剪贴板夹具构造 `ClipboardItem` 时失败，因此没有通过稳定版发布流水线。具体日志见 [Windows CI](https://github.com/Moresyl/nook/actions/runs/41575142489)。
- macOS／Linux 四个原生目标均已完成构建并上传。单元测试报告公开为 `native-tests-*.json`；测试失败不会阻止该 Alpha 打包，失败项目仍属已知问题，不能视为该系统已完成验证。Windows 稳定版完整验收条件保持不变。
- Linux x64 与 ARM64 的原生单元测试各 1818 项通过；这仍不等于完整原生桌面交互验收。
- 初次原生测试发现：Linux 与 macOS 有四项 Windows 文件锁测试缺少平台模拟，构建测试环境已修正。macOS Intel 与 Apple Silicon 的原生单元测试均为 1673 通过／145 失败，涉及插件／技能、Git worktree／快照、文件路径等；多项错误显示 `/var` 与 `/private/var` 的路径差异，尚未证明只是测试夹具问题，不能视为相关功能已通过该平台验收。完整报告随包公开。

## English

First public alpha of Nook, a local AI workspace with streaming chat, model comparisons, project editing/Git/terminal, MCP resources and tools, knowledge collections, plugins and scheduled tasks. This release adds automation status filters, rescheduling and clearer browser error recovery.

Downloads are available for Windows x64, macOS Intel/Apple Silicon, and Linux x64/ARM64. Windows: extract the complete ZIP and run Nook.exe. Keep the bundled resources, notices and source materials. Native unit-test reports are included as native-tests-*.json; failures do not block this explicitly unverified alpha. Both macOS architectures have 1673 passing and 145 failing tests, including paths, plugins/skills and Git worktrees/snapshots. Binaries are unsigned/not notarized. An intermittent shutdown timeout remains unresolved; full desktop acceptance has not passed. Back up your workspace before upgrading.
