## 能力集成范围

- **对话**：流式、停止／重试、编辑、分支、置顶／归档／搜索、Markdown／公式／图表、附件、导入导出。
- **模型**：多服务、本地模型、模型发现、凭据、连接配置、用量与上下文展示。
- **项目**：文件范围、文件树／编辑／预览、Git 状态／差异／审阅、终端、指令与项目隔离。
- **智能体**：工具执行、规划／目标流程、活动与权限、外部 CLI 适配、多个执行单元协作。
- **扩展**：技能、MCP 连接／发现／测试、插件工具与面板、导入与生命周期。
- **知识**：文档导入、可搜索资料集、检索与来源引用。
- **自动化**：持久化计划、执行历史、暂停／恢复、错误恢复、通知。
- **效率**：助手、提示模板、全局快捷键、快速聊天、托盘、听写／语音、翻译、备份。
- **媒体**：图片生成与理解、文档／产物预览、浏览器面板。
- **分发**：新产品元数据、旧产品身份清理、签名或明确未签名的安装行为、更新机制、Windows 发布，逐一审查目标平台。

导航项、占位界面或单一成功用例不代表能力完成。逐项实现状态、远程／SSH 等剩余工作及平台边界继续保留在[能力表](CAPABILITIES.md)和下方原始历史中。

## 验收与发布门槛

项目预览的专项及完整桌面记录还须包含文件标签证据：选中项可见、方向键与 Home／End 切换、未保存关闭取消、关闭后回焦、实际文件保存失败与重试，以及原有多文件草稿保留。六组明暗／缩放布局须保留实际按钮尺寸、可见性、无整页溢出和原始截图；缺失这些记录的旧包不得沿用。

浏览器记录还须包含多标签的独立历史／地址草稿、共享临时会话、仅选中视图可见、后台失败与关闭、原生新建／关闭／循环快捷键、最后一页清理及工作台重载释放全部标签。六组明暗／缩放布局须验证选中标签、24px 新建按钮、关联面板和精确原生边界，并保留 16 张额外原图；此前单页记录不能替代。

1. 验证当前源码的类型、单元覆盖率和构建；覆盖率仅对实际统计的模块有效。
2. 完成当前源码的实际桌面回归，检查成功、错误、取消、重试、重启、草稿和备份恢复。
3. 用最终源码构建安装版与便携版，审计产品身份、原始法律文件、原生组件及编译内容一致性。
4. 对同一应用体完成未安装与实际安装的完整桌面检查、设置、HTML 预览、PDF 阅读与原件恢复、便携、启动器、快捷方式、正常退出和保留数据的卸载。当前发布策略至少要求 267 项完整桌面检查及十一份匹配记录，包括 3 组记忆、10 组 HTML 预览（含 5 组停靠视图）、6 组 PDF 阅读、8 组 MCP PDF、八种协议的 PDF 文本传输隔离及 14 组浏览器、9 组快速聊天。停靠预览还须证明主界面重载释放旧视图、保留草稿和拒绝旧关闭请求；浏览器还须证明临时会话隔离、实际历史、重定向、停止地址恢复、错误重试、重载与重启，以及两主题三档缩放中的原生视图裁切和选中导航可见性。快速聊天证据包括独立草稿与受限桥接、PDF 原件／文本传输、停止与审批范围、工作台跳转、明暗／缩放、窗口／快捷键目标、保存失败重试及备份重启恢复；最小原生 420×360 的空白、长输入加附件及已有会话分别覆盖两主题与三档缩放，还要求工具栏键盘可达、延迟刷新保留输入和完整错误提示操作。具体门槛以发布策略代码为准，不能通过混用旧哈希或放宽断言满足。
5. 分别完成真实系统向导／选择器、物理输入、无障碍、真实云服务和目标平台检查；隔离测试替代边界不能冒充这些证据。
6. 检查前一版本、更新记录和实际提交，生成有事实依据的中英文说明、准确标签源码及 SHA-256，并通过标签流水线发布、核对下载文件。
