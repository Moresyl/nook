# 对话分支导航

有分支关系的对话顶部显示“查看对话分支”。打开后按原始关系和创建顺序查看同一组的起始对话、编辑分支、回复版本及编辑前记录。当前对话和已归档路径有明确标记；搜索按名称或模型做字面量匹配，选择一条路径可预览最后一条消息，再打开该对话。浏览、预览和切换不会请求模型。

各条路径保留完整消息、附件和独立草稿。切换先等待当前草稿保存，保存失败会保留输入、当前对话和所选路径，显示错误并允许重试。原有“打开原对话”快捷按钮继续保留，分支窗口内也可返回原对话。已归档路径可以继续使用。

每页显示 200 条，不截断分支总量。删除起始对话后，共用该起点的其他路径及其后续消息仍可一起浏览；已删除的目标刷新后不可打开。异常循环关系只在显示时断开并标记，不改写原有消息或关系。导航算法验证了 10,000 条对话组成的实际深链，避免递归栈溢出；界面的最大规模性能仍需单独测量。

最后一条消息的预览最多显示 4,000 个 UTF-16 单元，不拆开表情字符，也不执行 HTML。打开后读取完整内容。关系很深时，视觉缩进最多八层，实际路径和顺序完整保留。完整 JSON／gzip 备份保留这些关系、消息和草稿；恢复时沿用工作台现有的技能、插件新 ID 映射规则。

10 项分支合同测试达到语句、行、分支及函数 100% 覆盖率。真实 Electron 的五项分支检查已在 178 项完整源码回归中通过，覆盖 205 条路径的完整分页、精确上下文与草稿、实际保存失败与重试、路径删除、已有技能／插件的新 ID 映射、gzip 恢复及正常退出／重启。七张最终浅色、深色和 760×540 窗口的 100%／125%／150% 缩放截图已逐张检查，顶部七／八个操作、标题文字和模态按钮保持可见；标题截断时通过完整可访问名称及悬停文字读取。见 [运行时记录](../verification/conversation-branches-result.json) 和 [检查记录](../verification/conversation-branches-review-result.json)。当前应用包的验证状态见 [交付记录](DELIVERY.md)。

备份文件选择和确认采用独立测试进程中的原生对话框边界夹具；物理系统选择器、完整辅助技术、最大界面规模和其他平台仍需独立验收。临时聊天、并行模型比较和自由拖动的分支排序尚未实现。
