# 记忆

在设置的“记忆”中添加希望长期保留的偏好或事实。内容只在你主动保存后进入本机工作台，不会自动从聊天中提取。

- **全局**：用于普通聊天的后续请求。
- **项目**：只用于选择该项目的后续请求，同时仍可使用全局记忆。
- **临时聊天**：不读取任何记忆。
- **停用与删除**：不再用于后续请求，不能撤回已发送给模型的内容或修改已有备份。

启用的记忆会发送给所选模型服务，也可能用于该范围的自动任务。记忆不授予文件、命令或工具权限。不要把凭据当作记忆保存。

列表支持按内容或项目搜索，点击条目查看完整内容、编辑、切换范围或停用。每条最多 2,000 字符，全部最多 200 条、合计 32,000 字符；超限保存会失败，已有内容保持不变。删除需要确认，取消不改变数据。移除项目会删除该项目的记忆，不会将其变成全局记忆。

记忆随完整工作台备份保存。旧工作台没有记忆字段时按空列表读取；备份中的项目记忆必须引用存在的项目。修改适用于后续发起的请求，已运行请求使用发起时的上下文。

组件测试覆盖输入边界、作用域、临时聊天、更新／删除、原子容量限制、写入失败、真实文件持久化及重启、实际对话引擎请求。774 项全套组件测试、类型检查和构建通过；首次专项在启动阶段失败，见[组件批次记录](../verification/memories-component-result.json)。

调整启动依赖打包方式后，实际桌面 3 组专项通过：设置增删改、范围切换与停用、持久化、搜索、文本转义、明暗与窄窗口、取消／确认删除，以及移除项目时的清理。首次运行点击隐藏 input 的测试定位错误已改为点击可见标签并检查真实状态；没有使用强制点击。应用正常退出，[运行记录](../verification/memories-result.json)与[浅色](images/memory-settings-light.png)、[窄窗口深色](images/memory-settings-dark.png)截图均已核对。此结果不替代分发包、最大规模及物理无障碍验收。
