# 原生终端冷启动验证

远端 `37229762837` 通过 735 项单元测试、类型／法律检查及打包后，桌面回归通过 164 项，在项目 PowerShell 提示符等待中失败。原 10 秒期限内已有真实控制序列，但没有 `PS ` 提示符。失败后的独立观察在约 14.9 秒记录到提示符；后续截图同时保留未保存的代码草稿。该截图不代表原期限通过，具体冷启动耗时原因尚未确认。

测试现在将新终端首次提示符发现独立为最多 30 秒的冷启动检查，仍读取真实终端状态和输出，要求会话仍运行，记录实际耗时；无输出和无响应 IPC 都会明确失败。已启动终端的命令响应、输出内容、草稿、正常退出以及应用启动期限保持不变。此次调整的是验收预算，不是产品性能修复，也不会把之前失败改记为成功。

专项覆盖控制序列后的实际提示符、超过普通响应预算的冷启动、静默超时、已退出会话、IPC 错误、不返回的 IPC、同步操作耗尽期限及非法预算。产品仍选择已安装 PowerShell 7，并保留 Windows PowerShell 回退，不预热或替换实际被测终端。
