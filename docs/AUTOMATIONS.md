# 自动任务

侧边栏“自动任务”可保存任务名称、工作指令和模型连接，并选择一次执行、固定间隔或五字段 Cron。新任务默认暂停；开启“启用自动计划”后显示下次执行时间。固定间隔为 1 分钟至 30 天，Cron 使用明确的 IANA 时区；例如 `0 9 * * MON-FRI` 在该时区的工作日 09:00 执行，时区计算包含夏令时转换。一次计划须指定未来时间。

任务可选择助手、项目、聊天／只读项目分析／项目执行方式、MCP、本地技能、插件和资料集。这些选择进入现有对话引擎，沿用模型容量、输出预算、用量、知识来源快照及权限规则。选择资料集时，问题最多 2,000 字符；其他任务指令最多 32,000 字符。每次执行生成独立对话，不消费或替换未发送的聊天草稿。定时运行不提供工具自动批准：文件修改、命令及需审批的扩展调用仍会显示实际操作，等待用户审批。

“立即执行”可运行暂停中的任务，并保留原有自动日历。“暂停计划”只停止后续安排；“停止”取消当前回复和待审批工具，保留已生成内容。编辑时要求当前任务已停止。每个任务最多一个正在执行的运行，全局最多两个；其他到期任务按计划时间等待空位。任务可设置 1 至 60 分钟执行上限，默认 10 分钟，达到上限会取消当前运行。

开始运行前，执行记录与下一次自动时间一起落盘；一次计划在这个阶段被消耗。完成、失败和停止分别记录，最多保留最近 50 条记录，可从记录打开原对话。模型失败后仍保留对话和错误记录；重新执行会创建新对话。重复计划在下一次安排时继续运行，不把手动重试混入自然日历。删除任务会先暂停计划、停止当前运行，再移除配置，已经生成的对话仍然保留。

计划仅在应用进程运行时执行，当前不安装系统后台服务。关闭期间不补跑；重新打开时，将未确认完成的运行标记为已停止，将已过期的一次安排标记为错过，并将重复计划推进到下一个未来时间。已生成内容保持原样，不自动重新发送。休眠期间进程仍在运行时，唤醒后至多执行一次到期运行，后续间隔跳过积累的周期。超长时间使用有上限的计时器分段检查，系统时间后退时不会提前触发。

工作台写入失败会暂停调度并显示错误，防止模型先执行、记录却无法保存；检查磁盘后重新打开工作台可恢复。通知可单独启用，默认关闭。支持系统通知时，完成后会提示并可点击打开结果；真实操作系统通知送达、权限提示与不同平台仍需单独验证。

完整 JSON／gzip 备份包含任务配置、选择、执行记录和结果对话；密钥继续使用现有备份规则。恢复时先停止调度，再恢复数据，所有导入的任务都暂停，防止旧计划意外触发。技能和插件选择随完整扩展资产的新目录 ID 映射；恢复的插件仍需重新启用和授权。核对模型、项目位置、时区与选择后，再主动恢复计划。

验证包括真实文件落盘、一次／重复日历、跨夏令时、自然计时器、时钟后退、全局上限与排序、重叠拒绝、手动执行、暂停／停止／超时、持久化失败、关闭恢复、记录上限、扩展 ID 映射及真实对话引擎。桌面检查使用隔离本地 HTTP 模型和实际界面，另验证最小窗口下的最近聊天、导航与底部设置入口，检查未发送草稿不会被任务消费。真实云账号、系统通知送达、非正常进程终止、最大任务规模和其他平台不在当前验证结论中。竞品参考来自外部 AionUI、Cherry Studio 和 Goose 检出，产品调度与界面独立实现，没有导入竞品运行时代码。
