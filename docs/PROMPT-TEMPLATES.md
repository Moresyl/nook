# 提示模板

“助手 → 提示模板”可创建、编辑、搜索、复制和删除常用任务。模板保存在本地工作台，包含名称、简介和内容，独立于助手的系统工作指令。创建或编辑模板不会调用模型。聊天输入栏在有模板时显示“模板”入口，也可在模板列表中选择“使用模板”。

使用 `{{名称}}` 填写变量，例如 `请按 {{风格}} 改写 {{文本}}`。名称以中英文等 Unicode 字母或下划线开头，后续可包含字母、数字、下划线和短横线，最多 40 个字符；大小写不同视为不同变量。相同变量只填写一次，每处都使用同一个值。每个模板最多 20 种变量，前面加一个反斜杠（例如 `\{{文本}}`）会保留 `{{文本}}` 原文。不符合上述变量格式的标记保持为普通文本。

变量值按原文替换，保留换行、空格和 emoji，不再展开其中的其他变量，也不会执行表达式、HTML 或代码。填写后可查看完整纯文本预览；所有变量需填写非空内容才能追加。无变量的固定提示也可直接预览和使用。取消不会改变当前草稿。

“追加到草稿”会在已有文字后添加两个换行及完整提示，保留当前对话、模型、助手、项目、模式、附件及工具选择，沿用已有草稿保存和恢复流程。此操作不发送消息；确认草稿后可自行发送。模板删除后，已经展开的草稿和对话内容仍保留。保存草稿失败会保留输入，并通过现有错误提示和关闭保护流程报告，可在排除写入问题后继续编辑或重试保存。

单个模板内容最多 32000 个字符，单个变量值最多 32000 个字符，展开后及追加后的完整草稿分别不得超过 256000 个字符。工作台最多保存 200 个模板，模板记录的 JSON UTF-8 总大小不得超过 4 MB。超限的展开和追加会先报错，保留原草稿；模板保存仍使用完整工作台的串行原子事务，失败保留旧记录及编辑窗口。

完整工作台备份包含模板和已展开的草稿，恢复保留原有模板 ID；旧工作台或旧备份缺少此字段时使用空列表。单独的助手配置文件只分享助手指令，模板使用完整工作台备份保存，格式见 [助手配置文档](ASSISTANTS.md) 和 [备份文档](BACKUPS.md)。

单元检查覆盖精确限额、Unicode／转义／重复变量、字面量及自有字段、真实落盘和重启、并发容量、失败回滚、删除与完整备份。桌面检查使用真实管理／输入栏界面、实际 HTTP 模型请求、磁盘错误、重启和 gzip 备份；文件选取、替换确认及 EIO 使用隔离测试边界。最大规模性能、原生系统选取、其他平台和完整无障碍审计仍需单独验证。
